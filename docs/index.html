    Features

    Everything a small shop needs

    The full path from browsing to paying, plus the admin side to run the catalogue.

    Session-based cart

    Add, increase, decrease or remove products without an account. The cart lives in the Django session, and subtotals and the total are calculated from the database prices.

    Saved products

    Bookmark products to come back later, and move every saved product into the cart with a single click.

    Search and categories

    Search matches the name, description and category with Q objects. Empty, too long or unmatched searches return a clear message instead of an empty page.

    Stripe Checkout

    The cart total creates a Stripe Checkout Session in euros. Success or cancellation comes back to the store, which clears the cart and shows the result.

    Newsletter with Brevo

    Subscriptions are validated, stored without duplicates and answered with a welcome email sent through Brevo's transactional API.

    Catalogue managed in the admin

    Products, prices and up to five Cloudinary images each are managed from the Django admin, with flags that feed the home sections.

    cart/cart.pySession cart · simplified
    class Cart():
    def __init__(self, request):
        self.session = request.session
        self.cart = self.session.setdefault("cart", {})

    def add(self, product_id):
        product_id = str(product_id)
        if product_id not in self.cart:
            self.cart[product_id] = {"quantity": 1}
        else:
            self.cart[product_id]["quantity"] += 1
        self.session.modified = True  # persist the change
    ecommerce_app/views.pyStripe Checkout · simplified
    def checkout(request):
    stripe.api_key = settings.STRIPE_SECRET_KEY
    total = int(float(request.POST.get('total'))) * 100

    session = stripe.checkout.Session.create(
        payment_method_types=['card'],
        line_items=[{'price_data': {
            'currency': 'eur',
            'unit_amount': total,
            ...}, 'quantity': 1}],
        mode='payment',
        success_url=home_url + '?status=success',
        cancel_url=cart_url + '?status=cancel',
    )
    return redirect(session.url, code=303)

    Run it yourself

    Local setup

    You need Python 3, Node.js (for the Tailwind CLI), a PostgreSQL database such as a free Neon instance, and Cloudinary and Stripe accounts in test mode.

    1. Create a .env file with SECRET_KEY, DATABASE_URL, CLOUD_NAME, API_KEY, API_SECRET, STRIPE_PUBLIC_KEY, STRIPE_SECRET_KEY and, for the newsletter, BREVO_API_KEY.
    2. Run the migrations and create an admin user to load products.
    3. Run npm run dev to build the CSS and start Django and the Tailwind watcher together.
    Testing the checkout? With Stripe in test mode, pay with the test card 4242 4242 4242 4242, any future expiry date and any CVC. More cases are in Stripe's testing docs.
